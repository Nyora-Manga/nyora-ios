> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Nyora iOS 2.7.3 (build 12) at parity with Android 2.7.3: land the 31 in-flight files as logical commits, port Android catalogue filtering, refresh the parser engine from `nyora-data-driven`, and release an unsigned IPA via the existing `release.yml` tag workflow.

**Architecture:** Four sequential phases: (1) land uncommitted work in `nyora-ios` as 5 reviewed commits, (2) port Android-only changes, (3) rebuild `NyoraEngine.xcframework` in `nyora-ios-engine` from regenerated `SourcePatches.kt` and vendor it via Git LFS, (4) bug sweep, version bump, tag `v2.7.3`.

**Tech Stack:** Swift/Xcode (`Nyora.xcodeproj`), Kotlin + Gluon GraalVM native-image (engine), Git LFS, GitHub Actions.
